# Tugas API

Implementasi HTTP Request Method menggunakan REST API
dengan TypeScript, Bun, dan Elysia.

## HTTP Method

- GET
- POST
- PUT
- PATCH
- DELETE
- CONNECT

## Endpoint

### Mahasiswa

- GET `/mahasiswa`
- GET `/mahasiswa/:id`
- POST `/mahasiswa`
- PUT `/mahasiswa/:id`
- PATCH `/mahasiswa/:id`
- DELETE `/mahasiswa/:id`
- CONNECT `/mahasiswa/connect`

## Teknologi

- TypeScript
- Bun
- Elysia
- EchoAPI
